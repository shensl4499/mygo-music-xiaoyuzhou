# 小宇宙 for MyGo Music

把小宇宙的播客接进 MyGo Music。搜索播客和单集、翻完一档节目的全部历史、跟进订阅更新、收藏单集、读热门评论，音频由 MyGo 直接播放。

需要 MyGo Music **0.1.8 或更高版本**。

## 连接账号

1. 切到「小宇宙」源，点左上角的账号 → 登录。
2. MyGo 会显示一个二维码，**用小宇宙 App 的「扫一扫」扫描**，在手机上确认。
3. 二维码约 2 分钟失效，过期可重新生成。确认后插件会核对账号身份。

短信验证码登录**不受支持**：小宇宙网页对已注册手机号强制人机验证，插件里无法完成。

凭据只存在本机这个插件的 `host.storage` 里（access token、refresh token、device id），不上传、不写进日志和错误信息。退出登录即清除，过期会自动续期。

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 搜索 | 「歌曲」标签搜单集，「播客」标签搜播客，都支持分页 |
| 粘贴链接 | 粘 `xiaoyuzhoufm.com/podcast/…`、`/episode/…`，或 App 分享的 `xyzfm.link/…` 短链，按当前标签给出对应对象 |
| 播客页 | 订阅状态、全部历史单集（不止首页的 15 集）、热门单集 |
| 我的订阅 | 订阅与取消订阅，写完读回平台状态确认 |
| 收藏单集 | 与手机 App 的收藏互通 |
| 评论 | 热门评论，只读 |
| 音频 | `media.xyzcdn.net` 的 m4a 直链，由 MyGo 原生解码，不需要 ffmpeg |
| 侧栏页面 | 订阅更新、收听历史、分类列表与分类下的播客、主播页、热门单集 |
### 不支持

- 付费与私密单集 —— 列表里标为不可播
- 播放进度跨设备同步 —— 插件接口拿不到播放位置
- 发表评论与评论点赞 —— 只读
- 短信验证码登录
- 免登录浏览 —— 所有内容接口都要求登录
- 「查看全部」超过 300 条 —— 订阅更新与收听历史只列最近 300 条

## 为什么「查看全部」只有 300 条

小宇宙的订阅更新和收听历史按游标翻页，一页固定 15 条和 20 条，调大 `limit` 无效。宿主的 `browse` 页没有 offset，一次调用只能返回一屏，所以插件自己在里面连着翻页。

一个用了几年小宇宙的账号，订阅更新有四千多条，全部翻完要 300 多次请求、50 秒以上，超过宿主单次调用的时限。几百条之后也不会有人继续往下滑，所以插件在 300 条处停下，并在页面顶部写明只列了最近 300 条，更早的内容请回 App 查看。

## 风险与边界

本项目调用小宇宙的非官方私有接口，不是平台授权。接口可能变化、拒绝访问，也可能触发风控。

凭据由你主动扫码提供。插件不伪装官方客户端、不绕过验证码、不读其他应用的会话。

`xyzfm.link` 短链只用来取它指向的 id：不跟随跳转，也不打开平台网页，拿到 id 就交给 API。解析不出来时退回普通搜索，不报错。

订阅、收藏这类写操作只在你点击时发出，失败不重试；结果不确定时请到官方 App 核对。
